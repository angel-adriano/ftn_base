Purchase Request Portal

Allow employees to submit purchase requests without being registered as Odoo users.

🌐 Public Access

Employees can access the portal without logging in to Odoo.

🏢 Department-based Filtering

Select department first, then choose from employees in that department.

📝 Easy Form Interface

Simple, clean interface for submitting purchase requests with multiple product lines.

🔔 Automatic Notifications

Configured user receives notifications when new requests are submitted.

📱 Responsive Design

Works on desktop, tablet, and mobile devices.

Configuration

  1. Install the module
  2. Go to Settings → Purchase
  3. Configure the notification user in the Purchase Request Portal section
  4. Access the portal at: /purchase/request/portal

Dependencies

  • purchase_request
  • purchase_request_department
  • hr (Human Resources)
  • portal
  • web
